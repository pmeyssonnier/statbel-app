# Statbel Interviews — hébergement (GitHub Pages)

Dépôt **public** servant uniquement à héberger le code de l'application
(`index.html`) via GitHub Pages, pour un accès mobile fiable en `https://`
(ajout à l'écran d'accueil, rafraîchissement, persistance des données).

> Le développement et l'historique complet se font dans le dépôt **privé**
> `statbel-interviews`. Ici, seul le fichier final est publié.

## Confidentialité

- **Aucune donnée personnelle** n'est hébergée : GitHub Pages ne sert que le
  code. Toutes les données (contacts, CSV) restent **dans le navigateur** de
  l'utilisateur (IndexedDB), jamais sur le serveur.
- Géocodage par services publics belges (UrbIS / SPW / Geopunt).

## Mise à jour

Recopier la version à jour depuis le dépôt privé :
`enquetes_statbel.html` → `index.html`, puis commit + push.
